# Web3Yarn

A simple Web3Yarn Hub for Real time data processing.

Web3Yarn is aimed at developers who need a straightforward, dependable solution.

- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/Web3Yarn.git`
2. `cd Web3Yarn`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure Web3Yarn, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
